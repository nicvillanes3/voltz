# Voltz — Copa Interclasse de Vôlei

## Etapa 1: estrutura visual PHP
Esta versão contém o layout inicial e as páginas-base em PHP, com dados demonstrativos. Ainda não há conexão com MySQL nem autenticação funcional.

## Como abrir
1. Extraia a pasta `voltz_copa_interclasse` dentro de `C:\xampp\htdocs\`.
2. Inicie Apache no XAMPP.
3. Acesse `http://localhost/voltz_copa_interclasse/`.

## Próximas etapas
- Etapa 2: criar `banco.sql`, DER e dados iniciais conforme o desafio.
- Etapa 3: conexão PDO, login com `password_hash/password_verify`, sessões e proteção por perfil.
- Etapa 4: CRUDs completos e regras de edição, equipes, jogadores, partidas e mesários.
- Etapa 5: súmula validada no servidor, classificação em VIEW, geração de fases e histórico.

Os dados exibidos nas páginas são exemplos de interface, não resultados oficiais.
